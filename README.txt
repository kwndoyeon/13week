권역 상세 페이지 사진 넣는 법
- 권역 번호 폴더(z1 ~ z9)에 01.jpg, 02.jpg … 12.jpg 처럼 번호 이름으로 넣으면 자동으로 들어갑니다.
- 이름을 마음대로 쓰고 싶으면 photos.js 에 경로를 적으세요.
- 낮/밤 사진을 따로 쓰려면 photos.js 에서  1: { day: [...], night: [...] }  형태로 적으면 됩니다.
- 가로로 긴 사진(약 3:1)이 상자에 잘 맞고, 상자 크기에 맞춰 가운데 기준으로 잘립니다.
- 직접 찍은 사진이나 공공누리 등 사용 조건이 확인된 사진을 쓰고, 출처 표기 조건이 있으면 지켜 주세요.
