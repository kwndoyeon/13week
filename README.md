# Seoul O'Clock — A map of Seoul's population, Hour by Hour

## 실행
1. 터미널에서 이 폴더로 이동 → `node server.js`
2. 브라우저에서 http://localhost:3000
3. 실데이터 여부는 화면에 표시하지 않습니다. 개발자도구(F12) 콘솔에 `실데이터 로드 실패` 경고가 없으면 실데이터입니다.
   (style.css 의 `#status { display: none; ...` 에서 display: none 을 지우면 좌측 하단 상태 표시가 다시 보입니다)

> VS Code Live Server 나 파일 더블클릭으로 열면 서울시 API 가 CORS 에 막힙니다. 꼭 `node server.js` 로 여세요.

## 실데이터: [내국인] 행정동별 서울 생활인구(250m) (OA-23016)
- 기존 `SPOP_LOCAL_RESD_DONG` 은 2026-07-31 로 생산 종료 → 새 서비스 **`Spop250mLocalResdDong`** 사용
- 요청: `/{KEY}/json/Spop250mLocalResdDong/{시작}/{끝}/{YMD}/{TT}/{H_DNG_CD}`
- 응답: `YMD`(일자) · `TT`(시간) · `H_DNG_CD`(행정동코드 8자리) · `SPOP`(생활인구합계) · `M00~F70`(성·연령별)
- OpenAPI 는 **최근 2개월** 자료만 제공. 날짜를 비워 두면 (오늘-3일)부터 거꾸로 70일 동안
  "하루치가 다 들어온 가장 최근 날"을 자동으로 찾습니다. 특정 날짜를 쓰려면 `config.js` 의 `date: '20261115'`.
- 하루치(약 1만 행)를 1000건씩 약 11번 나눠 받습니다.
  - 브라우저: localStorage 에 캐시
  - 서버: `.cache/` 폴더에 캐시 → 한 번 받은 날짜는 API 가 느리거나 멈춰도 그대로 뜹니다 (발표 전에 한 번 열어 두세요)
- 행정동코드는 GeoJSON 의 `adm_cd2` 앞 8자리와 매칭. 코드가 안 맞는 동은 같은 구 평균 밀도로 채웁니다.

## 배경 지도
- `config.basemap = 'overture'` (기본): **Overture Maps** PMTiles 에서 수계·녹지·도로·철도·건물(줌 13 이상)을 흑백 톤으로 그림
  - `config.overture.releases` 의 최신 릴리스부터 열리는 것을 사용
  - Overture 공식 문서상 이 타일은 "확인용(production 비권장)" 이라 과제·시연용으로만 쓰세요
- Overture 가 안 열리면 자동으로 **OpenFreeMap Positron**(OSM, 키 불필요)을 흑백 처리해서 사용
- `'none'` 이면 배경 지도 없이 행정구역만
- 구조: 확대·이동은 기존 d3.zoom 이 담당하고, MapLibre 는 그 아래에서 카메라만 맞춰 그림 (`basemap.js` 의 `sync`)

## 권역 상세 페이지 (detail.html?zone=1~9)
- 들어가는 법: 메인 좌측 권역 목록 클릭, 또는 지도에서 더블클릭
- 왼쪽 = 낮(06~17시), 오른쪽 = 밤(18~05시). 같은 줄이면 왼쪽 h시 · 오른쪽 h+12시
- 가로축 0~10 = 상대 밀집도 (Low 0–2 / Moderate 2–5 / High 5–10), 빨간 선 = 시간대별 밀집도
  - "권역 안에서 상대값": 그 권역의 하루 최저~최고를 0.5~10 으로 → 하루 변화가 잘 보임 (기본)
  - "서울 9개 권역 비교": 9개 권역 × 24시간 중 최고 밀도 = 10 → 권역끼리 비교
- 사진 상자(블록)는 현재 꺼져 있음 (detail.js 의 SHOW_BLOCKS = true 로 다시 켤 수 있음)
- 사진: `photos/z{번호}/01.jpg …` 또는 `photos.js` 에 경로 지정 (photos/README.txt 참고). 없으면 낮 흰 상자 / 밤 검은 상자
- 데이터는 메인과 같은 API·캐시를 쓰고, 행정동코드 앞 5자리(자치구 코드)로 권역 합계를 냄

## 파일
| 파일 | 역할 |
|---|---|
| index.html / style.css | 레이아웃(스케치대로) |
| config.js | API 키·서비스명·날짜·배경지도·확대 단계 설정 |
| zones.js | 9개 권역 정의 |
| data.js | 생활인구 API (날짜 탐색 · 하루치 수집 · 캐시) · 데모 데이터 |
| basemap.js | 배경 지도 (MapLibre + Overture PMTiles / OpenFreeMap) |
| mosaic.js | 모자이크 그래픽 렌더러(점 격자, 글리프 7종) |
| app.js | 지도(d3) · 슬라이더 · 호버 · 확대 단계 전환 |
| detail.html / detail.css / detail.js | 권역 상세 페이지 |
| photos.js / photos/ | 권역별 사진 |
| server.js | 정적 서버 + API 프록시 + 응답 캐시 |

## 동작 규칙
- 슬라이더: 00:00 ~ 23:00. (재생 버튼은 없앴고, 스페이스바를 누르면 1시간씩 자동 재생/정지)
- 지도 확대 배율 `< 2.2` 권역(9) → `< 5.0` 자치구(25) → 그 이상 행정동. 지역 클릭 시 그 지역으로 이동하며 한 단계 세분화
- 평소: 서울 전체가 인구 모자이크로 채워짐 (`config.mapMosaic`)
  - 현재 단계(권역/구/동)의 지역마다 인구가 많을수록 칸이 촘촘 (`config.mapCell` 에서 단계별 칸 크기 조절), 칸마다 그 행정동 밀도에 따라 글리프 7단계
  - 시간 슬라이더를 움직이면 지역별 칸 크기와 글리프가 함께 바뀜. 지도 위 권역 번호(1~9)는 표시하지 않음
- 호버: 해당 지역의 모자이크가 붉은색으로 바뀌고 나머지는 어둡게. 모자이크 창 오른쪽 세로 슬라이더(드래그·스크롤)로도 시간 조절 가능, 반투명·블러 처리된 모자이크 창 + 좌측 세부정보(인구·24시간 곡선·순위)
- 모자이크: 인구가 많을수록 격자가 촘촘(칸 22px→7px), 칸마다 그 위치의 밀도에 따라 글리프 7단계
